# Hackathon Disclosure

CausalFly was created from scratch during the Meta Global AI Developer Hackathon beginning October 26, 2026.

Our team previously developed FruitFly XR, a separate Drosophila connectome simulation and mixed-reality research prototype.

No FruitFly XR source code or Git history is included in CausalFly.

CausalFly is a new open-source project focused on AI-assisted causal connectome experimentation, experiment provenance, control-versus-perturbation analysis, and scientific interpretation.
